# KN-004 — GENERAR PDF EN ESTA MAQUINA: no hay Python (ni `python` ni `python3`), asi que r

**fact:** GENERAR PDF EN ESTA MAQUINA: no hay Python (ni `python` ni `python3`), asi que reportlab/pypdf NO son opcion. Lo que SI funciona: Microsoft Edge headless, ya instalado. Comando verificado 2026-08-01 (genero un PDF de 11 paginas): "/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="C:\ruta\salida.pdf" "file:///C:/ruta/entrada.html" . Se escribe el documento en HTML con @page/@media print y sale un PDF con tipografia y maquetacion controladas.

**context:** Descubierto al generar el plan del asadero. Edge esta en Program Files (x86).

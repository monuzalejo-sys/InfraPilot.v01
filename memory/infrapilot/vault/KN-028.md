# KN-028 — proxy.ts redirected /sw.js and /manifest.webmanifest to /login (307) because nei

**fact:** proxy.ts redirected /sw.js and /manifest.webmanifest to /login (307) because neither path was in PUBLIC_PATHS. The build passed and each builder verified their own piece in isolation; the failure only surfaced running curl against the dev server. Fixed by adding both paths to PUBLIC_PATHS. Lesson: for any feature the browser requests without a session (PWA assets, webhooks, .well-known/*), always check the middleware/proxy matcher explicitly — a green build does not cover routes the middleware intercepts.

**context:** Found building the PWA feature (ROAD-006) 2026-07-28; caught live by orion-verifier, not by build/tsc.

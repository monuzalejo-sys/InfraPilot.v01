# KN-031 — Ownership overlap ACROSS waves (distinct from KN-026's same-wave case): builders

**fact:** Ownership overlap ACROSS waves (distinct from KN-026's same-wave case): builders 'quips' and 'origen-de-presupuesto' both touched presupuestos/page.tsx in different waves; the second restructured the page and the first builder's quips survived only in the detail view, not the list view. Per-wave disjoint ownership does not protect a file that gets touched again in a LATER wave. Found by reviewing the prerendered HTML, not the build. When planning multi-wave work, track which files were touched in prior waves and re-verify their state after any later wave that restructures them.

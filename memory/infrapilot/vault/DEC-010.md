# DEC-010 — Sistema de diseño canónico: skill estudio-diseno (El estudio del ingeniero moder

**title:** Sistema de diseño canónico: skill estudio-diseno (El estudio del ingeniero moderno)

**description:** El manifiesto visual del dueño vive como skill de usuario en ~/.claude/skills/estudio-diseno/SKILL.md (espejo en runtime/skills/estudio-diseno.SKILL.md): paleta EXACTA de blanco cálido (#F8F6F2 bg, #FCFBF8 cards, #171717 sidebar, #111111 ink, #666666 muted, #E7E4DE bordes, #F2EFE9 hover, #4D7C59/#B98A3C/#B94A48 estados), tipografía enorme y ligera con mucho aire, componentes como OBJETOS FÍSICOS (hoja técnica, plano desplegado, archivador, libreta de IA), botones-herramienta cápsula con glifo, composición editorial orgánica, microinteracciones 2px/180ms sin rebotes, IA como compañero silencioso (nunca chat protagonista), y prohibiciones explícitas (nada de azules eléctricos, morados, neones, gradientes tecnológicos, dashboards saturados, plantillas). TODA UI nueva o rediseñada debe invocar esta skill primero. Primera aplicación: landing de InfraPilot (commit 3aa86c6), verificada en navegador.

**reason:** El dueño rechazó landings previas por genéricas y entregó un manifiesto propio; convertirlo en skill evita que cada run reinvente (o repita el error).

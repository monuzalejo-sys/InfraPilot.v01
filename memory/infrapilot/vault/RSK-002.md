# RSK-002 — The ampacity tables in lib/electrica/circuitos.ts (IEC/NEC-based) are only MEDIU

**risk:** The ampacity tables in lib/electrica/circuitos.ts (IEC/NEC-based) are only MEDIUM-confidence reference data, explicitly declared as advisory and overridable by parameter. If the app is used under a different local code (e.g. Chile's NCh Elec. 4/2003) the built-in values could be wrong for that jurisdiction.

**probability:** Low

**mitigation:** Before presenting circuitos.ts results as authoritative engineering output in any jurisdiction other than IEC/NEC, validate the tables against the applicable local electrical code and expose them as clearly-labeled defaults the user can override.
